# QuickShare

PC를 파일 공유 서버로 만들어, 태블릿/폰 브라우저로 파일을 주고받는다.
외부 서비스를 전혀 거치지 않으므로 사내망 보안장비(SSL 검사)의 영향을 받지 않는다.

- 앱 설치 불필요 — 태블릿은 브라우저로 주소만 열면 된다
- 4자리 코드로 잠금 — 같은 네트워크의 다른 사람은 접근할 수 없다
- 의존성은 QR 생성용 `qrcode` 하나뿐

## 실행

**`QuickShare 실행.bat` 을 더블클릭한다.** 이 파일이 알아서 처리한다.

- Node 설치 여부를 확인한다
- 처음이면 `npm install` 을 돌린다
- 서버를 띄우고 2초 뒤 브라우저로 `http://localhost:4000` 을 연다
- 이미 실행 중이면 서버를 또 띄우지 않고 브라우저만 연다

창을 닫거나 Ctrl+C 를 누르면 종료된다.

> 배치 파일은 CP949 로, 줄바꿈은 CRLF 로 저장해야 한다.
> UTF-8 이나 LF 로 저장하면 cmd 가 파싱하지 못해 실행되지 않는다.

### 부팅할 때 자동으로 띄우려면

`Win+R` → `shell:startup` → 열린 폴더에 `QuickShare 실행.bat` 의 **바로가기**를 넣는다.
검은 창이 뜨는 게 거슬리면 바로가기 속성에서 실행 방식을 `최소화` 로 바꾼다.

### 직접 실행

```powershell
npm install
node server.js
```

실행하면 터미널에 QR 코드와 접속 주소, 4자리 코드가 표시된다.
코드는 실행할 때마다 새로 생성된다.

**폰·태블릿 카메라로 QR 을 찍는 것이 가장 빠르다.** 주소에 코드가 들어 있어서
스캔하면 입력 없이 바로 연결된다. IP 가 바뀌어도 QR 만 다시 찍으면 되므로
주소를 외우거나 확인할 일이 없다.

QR 은 PC 화면(`http://localhost:4000`)에도 표시된다.
카메라가 없으면 주소를 직접 열고 4자리 코드를 입력해도 된다.

### QR 에 담기는 주소

```
http://192.168.0.12:4000/?code=1234
```

`?code=` 를 읽어 인증한 뒤 주소창에서 지운다.
코드가 주소에 노출되므로 QR 과 `/api/qr` 은 PC 자신에게만 보여준다.

### 옵션

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `4000` | 사용할 포트 |
| `PIN` | 매번 임의 생성 | 코드를 고정하고 싶을 때 |

```powershell
$env:PORT=5000; $env:PIN='1234'; node server.js
```

## 화면은 보는 쪽에 따라 달라진다

서버는 접속자 IP로 **PC 자신(host)** 인지 **외부 기기(guest)** 인지 판별하고,
같은 폴더라도 이름을 뒤집어서 보여준다. 한쪽이 보낸 것은 반대쪽에서 받은 것이므로.

| | PC 화면 (host) | 태블릿 화면 (guest) |
| --- | --- | --- |
| 업로드 버튼 | 태블릿·폰으로 보내기 → `share/` | PC로 보내기 → `received/` |
| 받은 파일 | `received/` | `share/` |
| 보낸 파일 | `share/` | `received/` |
| 접속 코드 | 묻지 않음 | 필요 |

PC 앞에 앉은 사람에게 코드를 묻는 것은 의미가 없으므로,
루프백과 서버 자신의 LAN 주소에서 온 요청은 인증을 건너뛴다.

## 폴더

| 폴더 | 내용 |
| --- | --- |
| `received/` | 상대 기기에서 이 PC 로 보낸 파일 |
| `share/` | 이 PC 에서 상대 기기로 보낸 파일 |

`share/` 는 탐색기로 직접 파일을 넣어도 된다. 상대 기기 화면에 바로 뜬다.
같은 이름의 파일이 오면 덮어쓰지 않고 `사진 (1).jpg` 처럼 번호를 붙인다.

### ⚠ 재시작하면 두 폴더를 지운다

실행할 때마다 새 코드와 새 QR 로 **새 세션**이 시작되므로,
시작 시점에 `received/` 와 `share/` 안의 파일을 모두 삭제한다.

이 두 폴더는 저장소가 아니라 그 세션 동안만 쓰는 **임시 공간**이다.
**남길 파일은 서버를 끄기 전에 다른 곳으로 옮겨두어야 한다.**

지우지 않고 놔두려면 `server.js` 의 `clearTransferFolders()` 호출을 빼면 된다.

## 동작 방식

파일을 고르면 `PUT /api/upload` 로 본문에 파일을 그대로 실어 보내고,
서버는 그 스트림을 목적지 폴더에 바로 기록한다.
multipart 파싱이 없어서 큰 파일도 메모리에 올리지 않는다.

목록은 5초마다 갱신되고, 업로드가 끝나면 즉시 한 번 더 갱신한다.

PairDrop 같은 도구와 달리 WebRTC나 외부 신호 서버를 쓰지 않는다.
평범한 HTTP 요청이라 중간에 끊길 여지가 훨씬 적다.

## 잠금

- 코드가 맞으면 12시간짜리 토큰을 쿠키로 발급한다. 한 번 입력하면 다시 묻지 않는다.
- 코드 비교는 해시 후 `timingSafeEqual` 로 한다.
- 한 IP에서 10회 틀리면 10분간 차단된다.
- 업로드 파일명은 경로 요소와 Windows 금지 문자를 제거한 뒤 저장한다.

HTTP(평문)이므로 신뢰할 수 있는 사내망 안에서만 쓸 것.

## 접속이 안 될 때

1. **PC 방화벽** — node.exe 인바운드가 허용돼 있어야 한다.

   ```powershell
   New-NetFirewallRule -DisplayName "QuickShare" -Direction Inbound -Protocol TCP -LocalPort 4000 -Action Allow
   ```

2. **네트워크 격리** — 사내 와이파이에 클라이언트 격리(AP isolation)가 걸려 있으면
   유선 PC와 무선 태블릿이 서로 닿지 않는다. 이 경우 이 방식으로는 해결할 수 없고,
   같은 와이파이에 PC를 붙이거나 클라우드 경유 방식을 써야 한다.

   PC에서 태블릿 쪽으로 닿는지 확인:

   ```powershell
   Test-NetConnection -ComputerName <태블릿IP> -InformationLevel Detailed
   ```
